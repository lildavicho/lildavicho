### 🎙️ MercadoVoz — R&D

Exploring a voice-first system that transforms the natural language used by merchants into structured business operations.

Example:

```text
"Sold three boxes of tomatoes for fourteen dollars each."
```

↓

```json
{
  "type": "SALE",
  "product": "tomato",
  "quantity": 3,
  "unit": "box",
  "unit_price": 14,
  "total": 42
}
```

The goal is to explore how **AI + natural language interfaces** can make business software dramatically easier to use.

# 💡 Engineering Principles

> **Solve the problem before adding complexity.**

Some principles I try to follow:

- Build products around real user problems.
- Keep architecture understandable.
- Prefer maintainability over unnecessary cleverness.
- Treat security as part of the architecture.
- Design responsive interfaces with attention to detail.
- Validate assumptions before building large systems.
- Use AI as an engineering tool, not as a substitute for engineering.
- Test, lint, type-check and build before considering work complete.
- Document important technical decisions.
- Keep learning.
