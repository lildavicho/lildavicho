### MercadoVoz

An R&D project exploring a voice-first interface for business operations.

The idea is simple:

A merchant speaks naturally:

> "Vendí tres cajas de tomate a catorce dólares cada una."

The system interprets the sentence and transforms it into structured business information:

```json
{
  "type": "SALE",
  "product": "tomate",
  "quantity": 3,
  "unit": "caja",
  "unit_price": 14,
  "total": 42
}
```

The project explores the intersection between:
